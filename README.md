# Stat Bar 1.4.1

Extension สำหรับ Owlbear Rodeo แสดง HP / Max HP / Temp HP / AC เฉพาะโทเคนชนิด Character

## รูปแบบและหน้าจอควบคุม

หน้าจอหลัก เมนูโทเคน และหน้าตั้งค่าใช้ฟอนต์ Roboto / Noto Sans Thai กับไอคอนแบบมาตรฐาน ช่องตัวเลขใช้เลขความกว้างเท่ากันเพื่ออ่านค่าสถานะได้ง่าย โดยไม่ใช้ฟอนต์พิกเซลใน UI

ถอดสไตล์เปลวไฟวิญญาณออกแล้ว โทเคนที่เคยเลือกแบบนั้นจะกลับมาแสดงแถบ **คลาสสิก** โดยยังเก็บชื่อ HP / Max HP / Temp HP / AC และประเภทการมองเห็นเดิมไว้ ระบบเลือกสไตล์รายโทเคนยังอยู่เพื่อรองรับรูปแบบอื่นในอนาคต ปัจจุบันมีเฉพาะคลาสสิก

แถบคลาสสิกบนแผนที่ยังใช้ภาพเดิมและปรับความยาวตาม HP จริง กรอบคงรูปเดิมเมื่อ HP ลด

## แก้ค่าสถานะ

พิมพ์ตัวเลขเพื่อแทนค่า หรือ `+6`, `-6`, `20-5`, `/2` เพื่อคำนวณ แล้วกด Enter หรือออกจากช่อง HP ไม่เกิน Max HP เมื่อ Max HP มากกว่า 0

เมนูสามจุดมีชื่อ ช่องค่าสถานะ ประเภท และสไตล์ โดยไม่แสดงภาพแถบตัวอย่างหรือปุ่ม Damage/Heal

## ประเภทการแสดง

- **ทุกคนเห็นค่าสถานะ** — แสดงแถบและตัวเลข
- **ผู้เล่นอื่นเห็นเฉพาะแถบ HP** — ผู้เล่นอื่นเห็นแถบตามสัดส่วนจริง ไม่มีตัวเลข Temp HP หรือ AC และไม่มีขีดแบ่งช่วง ส่วน GM และผู้ควบคุมเห็นค่าครบ
- **เฉพาะ GM** — ซ่อนแถบจากผู้เล่น

GM เปลี่ยนประเภทได้ ผู้เล่นแก้ค่าสถานะหรือสไตล์ได้ตามสิทธิ์ Character ของห้อง ข้อมูลโหมดเจ้าของแบบเก่าจะอ่านเป็นเฉพาะ GM เพื่อไม่เปิดเผยข้อมูลโดยอัตโนมัติ

## ตั้งค่าทั้งห้อง

กดรูปเฟืองเพื่อเปิดหน้าต่างตั้งค่าแยกกลางจอ เลือกเหนือ/ใต้โทเคน ความกว้าง ระยะห่าง การแสดงตัวเลข และชื่อได้

ค่าพื้นฐานความกว้าง **1.0×** และระยะห่างที่แสดง **0** (ตำแหน่งภายใน -20) ใช้กับห้องที่ยังไม่มีค่าบันทึกไว้ ค่าที่ตั้งไว้แล้วจะยังคงอยู่ การตั้งค่า Scene แบบเก่าจะไม่ทับค่าห้อง

## อัปโหลดไป GitHub / Cloudflare Pages

อัปโหลดเนื้อหาทั้งหมดจากโฟลเดอร์ source รวม **public**, **src**, **scripts**, package.json และ package-lock.json ไปที่ repository เดิม

- Build command: `npm run build`
- Output directory: `dist`
- เพิ่มหรือใช้ Custom Extension เดิมจาก `https://stats-bar.pages.dev/manifest.json`

Cloudflare ติดตั้ง dependencies ด้วย lockfile ก่อน build แล้วสร้างภาพแถบคลาสสิกที่ `public/bars-v7/` ไม่ต้องมีโฟลเดอร์ artwork หรือไฟล์ฟอนต์ตัวเลขพิกเซลใน public/fonts

หาก deploy แบบอัปโหลดไฟล์สำเร็จรูป ให้ใช้เนื้อหาใน ZIP deploy แทน source ไม่อัปโหลด node_modules หรือโฟลเดอร์ .git

## พัฒนาและตรวจสอบ

```sh
npm ci
npm run dev
npm test
npm run build
```

ทดสอบการคำนวณ สิทธิ์ การอ่าน metadata สไตล์แยกต่อโทเคน ภาพ PNG และความโปร่งใส การลดแถบตาม HP การเปลี่ยนสไตล์กลับ การตามตำแหน่งโทเคน และการรวมคำขอเขียนตั้งค่า

`tests/style-preview.html` ใช้ตรวจภาพที่เลือดศูนย์ ตัวเลขหลายหลัก และโหมดซ่อนตัวเลข ส่วน `tests/ui-preview.html` แสดงแผงหลักกับเมนูสามจุดตามขนาดจริง

## ความเข้ากันได้

ชื่อและไอคอน Extension เปลี่ยนเป็น **Stat Bar** โดยเก็บ metadata key เดิม `com.pixel-statbar/stats`, `com.pixel-statbar/settings`, `com.pixel-statbar/overlay` เพื่ออ่านข้อมูลที่มีอยู่ต่อได้ ไม่ต้องสร้าง Extension ใหม่หรือลบค่าสถานะเดิม

แถบเป็น local overlays ที่ผูกกับโทเคน ไม่มีการเขียนตำแหน่งโทเคนร่วมเพื่อให้แถบตามการลาก ภาพตัวเลขเป็นไฟล์คงที่ ข้อมูลตัวละครไม่ถูกฝังใน URL ภาพ

Stat Bar เป็น Extension อิสระ ไม่ใช่ผลิตภัณฑ์อย่างเป็นทางการของ Owlbear Rodeo หรือ Stat Bubbles for D&D หากเปิด Stat Bubbles พร้อมกัน อาจเห็นแถบสองชุด ข้อมูลจาก Extension อื่นไม่ได้ถูกนำเข้าอัตโนมัติ
